# Potencia Bootstrap

Execute o bootstrap operacional completo do Potencia.

1. Leia CLAUDE.md.
2. Leia os três prompts em prompts/.
3. Leia MANIFEST.json, bootstrap/BOOTSTRAP.md e bootstrap/AGENT-POLICY.md.
4. Detecte o ambiente.
5. Instale, configure, ative e verifique os componentes aplicáveis.
6. Registre o estado em .potencia/runtime-state.json.
7. Não declare sucesso sem Final Gate.

O comando é um atalho para o contrato do Potencia; não substitui suas regras.
