# 02 — Specification + Architecture Gate

Produzir somente documentação necessária, classificando cada documento como REQUIRED, NOT REQUIRED ou NOT APPLICABLE.

Possíveis docs: PROJECT, PROBLEM, REQUIREMENTS, BUSINESS-RULES, ACCEPTANCE-CRITERIA, ARCHITECTURE, TECH-STACK, DATA-MODEL, API-CONTRACTS, SECURITY, UX-FLOWS, IMPLEMENTATION-PLAN, DECISIONS, RISKS.

Hard gate: decisão/requisito essencial incompleto = não implementar e não delegar implementação. Parar e perguntar.
