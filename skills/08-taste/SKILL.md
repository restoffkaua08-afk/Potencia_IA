# Taste

## Papel

Skill de design frontend para reduzir interfaces genéricas e melhorar composição, tipografia, espaçamento, hierarquia, movimento e estados de interação.

## Fonte selecionada

https://github.com/tyfarrago-hub/taste

A fonte foi fixada para evitar confusão com outros projetos chamados Taste.

## Instalação

A instalação documentada copia as skills para o diretório de skills do Claude Code:

git clone https://github.com/tyfarrago-hub/taste.git
cp -r taste/skills/* ~/.claude/skills/

Depois, reinicie o Claude Code.

No Windows, adapte a cópia para PowerShell mantendo a mesma origem e destino.

## Uso

As skills aparecem como comandos/skills do Claude Code. Use-as somente quando o trabalho envolver frontend/design.

Não substitui engenharia funcional, acessibilidade técnica, testes, revisão ou as camadas Emil e Impeccable.
