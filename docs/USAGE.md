# Usage

## First run

1. Abra `CLAUDE.md`.
2. Leia os três prompts.
3. Verifique `MANIFEST.json`.
4. Prepare os componentes descritos em `projetos/` e `plugins/`.
5. Execute o ciclo definido pelo Prompt 02.
6. Use o Prompt 03 para missões longas/autônomas.

## Important

Os arquivos `projetos/*.md` e `plugins/*.md` são contratos/instruções da infraestrutura; eles não baixam automaticamente os projetos externos.

A instalação concreta depende do ambiente do agente e deve ser verificada no repositório oficial.

Nunca coloque tokens, chaves ou credenciais no Potencia IA.
