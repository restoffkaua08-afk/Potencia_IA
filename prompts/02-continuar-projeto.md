# Prompt 02 — Execução

Ciclo obrigatório:

ENTENDER → DESCOBRIR → ESPECIFICAR → ARQUITETAR → PLANEJAR → DELEGAR → EXECUTAR → OBSERVAR → TESTAR → VERIFICAR → REVISAR → CORRIGIR → VERIFICAR NOVAMENTE → VALIDAR → LIMPAR → SELAR

Use as skills 01–05 como gates. Antes da implementação, requisitos e decisões essenciais devem estar definidos.

É obrigatório ativar os agentes/projetos configurados quando forem apropriados; skills não substituem agentes.

Loop de cada unidade:
PLAN → ASSIGN → EXECUTE → OBSERVE → TEST → VERIFY → ACCEPT / FIX / BLOCK

Verificação:
DEFINE → BREAK → VERIFY → VERDICT

Após implementação, revisão adversarial independente quando possível. Corrija achados e verifique novamente.

Para frontend, use Emil, Impeccable e Taste quando aplicável.

Cleanup só após validação do usuário. Seal depois do cleanup.
