# Prompt 01 — Iniciar Projeto

Leia `CLAUDE.md`, este prompt, os prompts 02 e 03 e `MANIFEST.json`.

Prepare a infraestrutura antes de implementar:
1. explique cada pasta e componente;
2. localize os repositórios oficiais;
3. instale/configure os projetos/agentes quando suportado;
4. prepare plugins;
5. localize e leia skills relevantes;
6. verifique versão, configuração e funcionamento;
7. registre limitações.

Estados: INSTALLED, CONFIGURED, VERIFIED, BLOCKED, NOT AVAILABLE.

Nunca declare instalação/ativação sem evidência.

Não implemente o projeto do usuário nesta etapa.
