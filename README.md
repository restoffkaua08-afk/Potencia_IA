# Potencia IA

Infraestrutura reutilizável para Claude Code e agentes compatíveis.

Comece por `CLAUDE.md`, depois leia os três prompts em `prompts/`.

Estrutura:
- `plugins/` infraestrutura auxiliar
- `projetos/` projetos/agentes externos
- `skills/` metodologia de produção
- `task-observer-workspace/` laboratório experimental
- `prompts/` operação
- `docs/` documentação complementar

Skills definem metodologia. Agentes executam. Plugins fornecem infraestrutura.
